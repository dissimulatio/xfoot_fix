Статичная камера как в старом York'e и вход в лобби через Вход 1 и Вход 2.

Как установить:
Открыть папку игры.
Перейти в resources\app.
Закинуть туда main.js и preload.js из папки xfoot fix.
Согласиться на замену файлов.
Полностью перезапустить xFootball.
